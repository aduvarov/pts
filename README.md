## 15.11. Упражнение - Ffmpeg executor

**Цель:** Создать FFmpeg Executor для обработки видеофайлов в рамках модульного приложения.

**Структура содержания:**

1.  **Подготовка основ:**
    -   Создание файла `FFmpegExecutor.ts`.
    -   Наследование от абстрактного `CommandExecutor`.
2.  **Определение необходимых типов:**
    -   Создание `IFfmpegInput` для описания входных данных.
3.  **Реализация основных методов:`**
    -   **Конструктор:**
        -   Инициализация и передача `ILogger` для совместимости модулей.
    -   **Инициализация зависимостей:**
        -   Создание экземпляров `FileService` и `PromptService`.
    -   **Методы ввода и обработки данных:**
        -   Имплементация методов для получения основных параметров (ширина, высота, путь, имя файла).
        -   Строительство аргументов команды через FFmpeg builder.
4.  **Расширение типов для команд:**
    -   Добавление output в интерфейс для поддержки удаления файлов.
5.  **Реализация исполнения команды:**
    -   Удаление выходного файла перед выполнением.
    -   Исполнение FFmpeg команды с заданными параметрами.
6.  **Обработка вывода команды:**
    -   Использование `StreamHandler` для обработки вывода с заданной конфигурацией логирования.
7.  **Заключительная реализация и тестирование:**
    -   Интеграция реализованного executor в приложение.
    -   Проверка функциональности и модульности решения.
