## 15.7. Упражнение - Консольный вывод

В этом уроке мы рассматриваем создание консольного логгера в качестве части нашей системы логирования. Мы используем созданный ранее универсальный класс `StreamLogger` для реализации специализированного логгера, выводящего данные в консоль.

#### Шаги Реализации:

1.  **Создание Класса** `ConsoleLogger`:
    -   Разработка класса, наследующего функционал `StreamLogger` для реализации вывода в консоль.
    -   Данный класс является первым примером адаптации общего решения под конкретный выход данных.
2.  **Применение Паттерна "Синглтон"**:
    -   Для того, чтобы `ConsoleLogger` мог быть использован повсеместно без необходимости создания множества его экземпляров, реализуем его как синглтон.
    -   Включение статического свойства для хранения единственного экземпляра логгера.
    -   Реализация статического метода `getInstance()`, который возвращает существующий экземпляр или создает новый при его отсутствии.

#### Инструкция по Реализации:

-   **Шаг 1**: Определить класс `ConsoleLogger`, реализующий интерфейс `IStreamLogger`.
-   **Шаг 2**: Внутри класса, определяем методы для различных операций логирования (например, вывод ошибок или завершения работы).
-   **Шаг 3**: Добавить статическое свойство `logger`, в котором будет храниться экземпляр `ConsoleLogger`.
-   **Шаг 4**: Реализовать статический метод `getInstance` для доступа к экземпляру логгера:
    -   Проверить, существует ли уже экземпляр логгера.
    -   Если нет, создать новый и сохранить в статическом свойстве.
    -   Вернуть экземпляр логгера.
