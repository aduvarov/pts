## 15.9. Упражнение - Builder для ffmpeg

#### Цель

Создать удобную структуру для сборки команд FFmpeg с использованием паттерна "билдер".

#### Почему билдер?

-   **Удобство**: позволяет собирать команду из различных опций путём вызова методов.
-   **Гибкость**: подходит для создания сложных команд, таких как команды FFmpeg.

#### Структура билдера

-   **Расположение**: `ffmpeg.builder.ts`.
-   **Элементы команды**: команда (FFmpeg) и аргументы (массив строк, включающий параметры ввода, кодек, разрешение видео и выходной файл).
-   **Инициализация**: начинается с указания пути к входному файлу, следующие параметры включают кодек, разрешение видео и путь к выходному файлу.

#### Реализация

1.  **Определение класса**: `export class ffmpegBuilder {}`.
2.  **Состояние**:
    -   Входной файл (`input`),
    -   Выходной файл (`output`),
    -   Промежуточные опции (например, разрешение видео).
3.  **Начальные значения**: через конструктор задаются начальные опции, такие как кодек.
4.  **Методы**:
    -   **Установка входного файла**: сохраняет путь к файлу.
    -   **Установка размера видео**: сохраняет размер видео в опциях.
    -   **Установка выходного файла**: выполняет проверки, собирает и возвращает итоговый набор аргументов команды.
5.  **Возвращение** `this`: каждый метод, кроме последнего, возвращает ссылку на текущий объект билдера для цепочки вызовов.

#### Пример использования

С помощью цепочки вызовов методов билдера можно собрать нужную команду FFmpeg, настраивая различные параметры, такие как путь к файлам, кодек, разрешение видео.
