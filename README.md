## 11.5. Import и export

#### Экспорт в TypeScript

-   **Основы экспорта**: В TypeScript можно экспортировать как обычные JavaScript объекты (классы, константы), так и типы (интерфейсы, Type). Типы существуют только во время компиляции.
-   **Дефолтный экспорт**: Поддерживается экспорт по умолчанию для объектов JS, но не для типов. Допускается только один дефолтный экспорт на модуль.

#### Импорт в TypeScript

-   **Дефолтный импорт**: Можно импортировать дефолтные экспорты с возможностью переименования.
-   **Импорт специфических элементов**: Позволяет импортировать конкретные экспортированные элементы потребительского модуля.
-   **Импорт всех элементов**: Синтаксис `import * as name` позволяет импортировать все экспортированные элементы под одним именем, включая дефолтный экспорт.
-   **Комбинированный импорт**: Можно комбинировать дефолтный импорт с импортом конкретных элементов.
-   **Импорт типов**:
    -   TypeScript допускает импорт типов аналогично обычным элементам.
    -   Существует специальный синтаксис `import type` для импорта исключительно типов, упрощающий оптимизацию и кодогенерацию.

#### Отличия от ES6 и Совместимость

-   TypeScript расширяет синтаксис ES6, добавляя специфику работы с типами.
-   Модульная система TypeScript обеспечивает полную совместимость с ES6, позволяя использовать стандартные формы экспорта и импорта.
-   Примеры в лекции демонстрируют работу с модулями в контексте как CommonJS, так и ES6, указывая на возможность использования различных модульных систем.
