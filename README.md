## 11.6. Типизация сторонних библиотек

#### Подключение библиотек:

1.  **С поддержкой TypeScript:**
    -   Большинство современных фреймворков поддерживает TypeScript "из коробки".
    -   Некоторые библиотеки уже включают типы в свои пакеты (пометка TypeScript или синий значок на NPM).
2.  **Библиотеки без встроенных типов:**
    -   Ищем типы на DefinitelyTyped (`@types/название_библиотеки`). Если они есть, устанавливаем их.
    -   Если типов нет, варианты использования:
        -   Использовать библиотеку без типизации, игнорируя TypeScript (не рекомендуется).
        -   Самостоятельно создать файл с определениями типов для библиотеки.

#### Создание собственных типов для библиотек:

1.  Получаем информацию о сигнатуре функций библиотеки из её исходного кода.
2.  Создаём файл определения типов `.d.ts`.
3.  Используем ключевое слово `declare` для объявления модуля и функций.
4.  Описываем типы для аргументов функций и возвращаемые значения.

#### Практика:

-   Пример с библиотекой для работы с JSON, где нет встроенных типов.
-   Создание `.d.ts` файла с типами для функций этой библиотеки.
-   Использование созданных типов в проекте для обеспечения типобезопасности.

#### Вклад в сообщество:

-   Можно контрибьютить в DefinitelyTyped, добавляя типы для популярных библиотек и делиться ими с другими разработчиками.
