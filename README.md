## 12.1. Порождающие паттерны

Введение в порождающие паттерны проектирования начинается с подчеркивания их основной особенности: они предназначены для создания новых объектов или целых групп объектов, отсюда и название "порождающие".

#### Четыре основных порождающих паттерна:

1.  **Фабрика (Factory)**:
    -   Назначение: Упрощение создания объектов разных классов без указания конкретных классов.
    -   Применение: Особенно полезен в больших приложениях для облегчения переиспользования кода.
2.  **Одиночка (Singleton)**:
    -   Назначение: Гарантирует единственность экземпляра класса для всего приложения.
    -   Применение: Используется для централизованного управления ресурсами или данных в приложении.
3.  **Прототип (Prototype)**:
    -   Назначение: Позволяет создавать новые объекты путем клонирования существующего объекта.
    -   Применение: Используется, когда создание копии объекта предпочтительнее его инициализации с нуля.
4.  **Строитель (Builder)**:
    -   Назначение: Облегчение создания объектов сложной структуры пошагово.
    -   Применение: Полезен, когда необходимо создавать различные представления объекта без загрязнения конструктора.

Эти паттерны играют ключевую роль в проектировании гибких, масштабируемых и легко поддерживаемых программных систем, обеспечивая удобные механизмы для создания и управления объектами.

Далее мы более детально рассмотрим каждый из этих паттернов на примерах, начиная с паттерна "Фабрика".
