## 13.3. Facade

**Что такое Фасад?**

Фасад - это структурный паттерн, который позволяет скрыть сложность системы, предоставив простой интерфейс для взаимодействия.

**Примеры использования:**

-   Отправка уведомления в Telegram: пользователь просто пишет сообщение и нажимает Enter, не задумываясь о том, что происходит внутри системы.
-   В программировании: скрытие сложности модулей за простым API.

**Проблема:** Предположим, вам нужно отправить уведомление. В системе есть сервисы для отправки нотификаций, логирования, создания email-шаблонов. Чтобы отправить сообщение, придется взаимодействовать со всеми этими сервисами по отдельности.

**Решение с использованием паттерна Фасад:** Вместо взаимодействия с каждым сервисом напрямую, создается фасадный класс (например, `NotificationFacade`), который предоставляет удобный и понятный метод (например, `send`), скрывая за собой всю внутреннюю логику и взаимодействие с другими сервисами.

**Пример реализации:**

-   Классы `Notify`, `Log`, `Template`, каждый выполняет свою функцию (отправка нотификаций, логирование, работа с шаблонами).
-   Класс `NotificationFacade` использует эти внутренние сервисы, предоставляя один метод `send`, через который осуществляется весь необходимый функционал.

**Преимущества:**

-   Упрощение взаимодействия с системой для внешних пользователей.
-   Улучшение структуры кода за счет сокращения зависимостей.
