## 15.5. Обработка ввода

#### Цель Лекции:

Представить и реализовать core-сервис для обработки пользовательского ввода, который будет универсально применяться к различным типам данных.

#### Основные Моменты:

-   **Создание Сервиса**:
    -   Инициализация core-сервиса под названием `PromptService` в файле `promptService.ts`.
    -   Разработка метода для обработки ввода `inputPrompt`.
-   **Инструменты и Технологии**:
    -   Использование библиотеки `inquirer` для содействия в обработке ввода.
    -   Создание метода `inputPrompt` для получения данных от пользователя через консоль.
    -   Обработка типов ввода: текстовых данных, чисел и паролей.
-   **Реализация**:
    -   Метод `inputPrompt` принимает параметры `message` (сообщение пользователю) и `type` (тип ожидаемого ввода).
    -   Типы ввода `promptType` ограничены значениями: `input`, `number`, и `password`.
    -   Поддержка универсальности обработчика ввода за счет возможности работы с различными типами данных.
    -   Пример использования сервиса для запроса числового ввода и последующая обработка полученного результата.
