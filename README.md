## 11.2. Namespaces и reference

#### Референсы:

-   Референсы во фреймворках: Иногда используются для ссылок на типы, например, в Next.js.
-   Ограничения использования: Рекомендуется ограниченное использование референсов за исключением случаев работы с типами в определённых фреймворках.
-   Сборка кода: Референсы не являются лучшей практикой для сборки кода. Пример сборки в один файл и его недостатки.

#### Namespaces:

-   Определение: Позволяют инкапсулировать логику или объекты, подобно классам, но могут содержать любые элементы (константы, интерфейсы и т.д.).
-   Примеры использования: В контрактах, например, для инкапсуляции интерфейсов запроса и ответа.
-   Применение: Наиболее полезны на бэкенде для структурирования и инкапсуляции кода.

#### Особенности и рекомендации:

-   Использование `export` для доступности элементов из namespace.
-   Предостережение от использования namespaces на фронтенде из-за ограничений определённых сборщиков.
-   Различие между старыми модулями TypeScript (модуль) и современным использованием namespaces.
-   Рекомендация использовать namespaces с умом, для организованной инкапсуляции, и избегать референсов для кода вне типов.
