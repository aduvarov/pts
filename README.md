## 12.4. Prototype

#### Вступление

-   Что такое паттерн "Прототип".
-   Различие между паттерном "Прототип" и использованием prototype в JavaScript.

#### Основная концепция

-   Паттерн "Прототип" позволяет клонировать объекты без необходимости их повторного создания с нуля.
-   Особенно полезен для объектов с большим количеством параметров, которые надо скопировать.
-   В JavaScript, благодаря механизму prototype, можно изменять прототип объекта, позволяя создавать новые экземпляры с предопределёнными характеристиками.

#### Применение

1.  **Сценарий использования**: клонирование пользовательской истории с возможностью модификации отдельных параметров.
2.  **Разработка прототипа**:
    -   Создание интерфейса Prototype с обязательной функцией клонирования.
    -   Введение класса UserHistory, который реализует интерфейс Prototype.
    -   Реализация конструктора и метода клонирования в классе UserHistory.

#### Реализация на примере

1.  **UserHistory** — класс со свойствами email и name.
2.  **Метод клонирования**:
    -   Копирование всех характеристик существующего объекта UserHistory.
    -   Возврат нового объекта UserHistory с идентичными данными.

#### Пример кода

1.  Создание экземпляра UserHistory.
2.  Клонирование объекта через вызов метода clone(), создание независимого клона.
3.  Возможность модификации клона без влияния на оригинальный объект.

#### Выводы

-   Паттерн "Прототип" обеспечивает эффективное клонирование объектов, сохраняя их независимость.
-   Это упрощает работу с объектами, которые необходимо копировать, обновляя лишь часть свойств.
-   Использование данного паттерна повышает эффективность и читаемость кода, избегая необходимости ручного копирования объектов.
