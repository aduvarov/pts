## 15.1. Проект - Утилита выполнения команд

#### Цель видеоролика

-   Обсудить требования для запуска проекта.
-   Объяснить, как преодолеть возможные технические трудности.

#### Проект

-   Разработаем видеоконвертер.

#### Особенности проекта

1.  **Скрипт:** простой скрипт, а всего 43 строки.
2.  **Инструмент:** Command Executor для выполнения любых команд.

#### Требования

-   **FFmpeg:** Необходим для конвертации видео.
    -   **Установка:**
        -   **Windows:** Скачать с официального сайта или использовать Homebrew.
        -   **Mac:** Установить через Homebrew.
        -   **Linux:** Установить с помощью apt-get.
    -   **Проверка установки:** Запуск FFmpeg для проверки версии.

#### Решение проблем

-   При возникновении проблем:
    -   Используйте репозиторий проекта для получения помощи.
    -   Обратитесь к исходному коду уроков для сравнения вашего кода с образцом.
