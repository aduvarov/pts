## 11.1. Модульность и библиотеки

**Цели лекции:**

-   Осветить концепции модульности, актуальные для JavaScript и TypeScript.
-   Разобрать различия между подходами к организации модулей в браузерах и Node.js.
-   Объяснить возможности TypeScript в контексте работы с модулями.

**Основные пункты:**

1.  **Введение в модульность**:
    -   Модульность важна для эффективной организации кода.
    -   Есть различие в подходах к модульности в браузере и в Node.js.
2.  **Модульность в JavaScript и TypeScript**:
    -   Возможность сборки разрозненных файлов проекта в один через TypeScript.
    -   Использование сборщиков (например, Webpack) и референсов.
3.  **Стандарты модулей**:
    -   Исторически разные подходы — от IIFE до CommonJS и ES модулей.
    -   Текущее использование CommonJS на сервере (Node.js) и ES модулей в браузерах.
4.  **Использование CommonJS и ES модулей**:
    -   CommonJS хорошо работает на Node.js.
    -   Для браузера CommonJS требует сборки через инструменты (например, Webpack).
    -   ES модули поддерживаются современными браузерами и Node.js (с оговорками).
