## 14.2. Chain of Command

**Введение:**

-   Введение в паттерн "Цепочка вызовов" (Chain of Command), примеры использования в веб-разработке.

**Концепция:**

-   Представление ситуации с обработкой HTTP запроса через API, где необходимо учесть авторизацию, валидацию и бизнес-логику.
-   Проблема разрастания кода и дублирования при отсутствии цепочки вызовов.

**Решение:**

-   Использование Middleware как реализация паттерна "Цепочка вызовов" для упрощения и улучшения структуры кода.

**Практика:**

1.  **Создание интерфейса Middleware:**
    -   Описание метода next, указывающего на следующий обработчик.
    -   Метод handle для непосредственной обработки запроса.
2.  **Реализация абстрактного класса Middleware:**
    -   Пример реализации next метода и условия передачи обработки дальше по цепочке.
3.  **Примеры конкретных Middleware:**
    -   Создание AuthMiddleware для проверки авторизации пользователя.
    -   Создание ValidateMiddleware для валидации входящих данных.
4.  **Контроллер:**
    -   Создание заключительного обработчика запроса.
5.  **Цепочка вызовов:**
    -   Демонстрация последовательного связывания middleware и контроллера для обработки запроса.

**Примеры использования:**

-   Цепочка вызовов в различных ситуациях: авторизация, валидация, выполнение различных преобразований данных.
