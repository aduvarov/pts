## 15.10. Работа с файлами

**Цель**: Создать сервис для работы с файловой системой, который будет использоваться в обработке команд, включая функционал формирования полного пути файла и возможность его удаления.

**Местоположение**: Код располагается в секции Core, поскольку работа с файлами является базовой функцией для многих команд.

**Структура Создания**:

1.  **Подготовка**: Создаем папку `files` в Core для будущей обработки файлов и файл `service.js` для сервисных операций.
2.  **Реализация Получения Пути Файла**:
    -   Используем метод `getFilePath`, принимающий путь (`string`), имя файла (`string`), и расширение файла (`string`).
    -   При формировании пути учитываются возможные относительные и абсолютные пути. Для обработки используем методы Node.js `path.join` и `path.dirname`.
    -   В случае относительного пути, он дополняется информацией о текущей директории.
3.  **Операция Удаления Файла** (если он существует):
    -   Создаем метод `deleteFileIfExists`, который получает путь к файлу (`string`).
    -   Внутренний метод `isExists` используется для проверки существования файла через функцию `fs.promises.stat`.
    -   Если файл найден, то применяется `fs.promises.unlink` для его удаления.
