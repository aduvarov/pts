## 11.4. Модульность на frontend

#### Введение:

В этом материале мы рассмотрим, как подготовить TypeScript проект для использования в браузере, предложив два основных подхода: сборка в один файл и использование современных ES-модулей.

#### Сборка в Один Файл:

1.  **Инструменты Сборки**: для объединения всех файлов в один бандл можно использовать инструменты вроде Webpack или Rollup. Для работы с TypeScript потребуется дополнительный лоадер или плагин для этих инструментов.
2.  **Проблемы Сборки в Один Файл**: хотя сборка в один файл выглядит привлекательно, она требует дополнительных скриптов или настройки модульной системы (например, AMD или SystemJS) для поддержки модульности.

#### Использование ES-модулей:

1.  **Конфигурация TypeScript**: сохраните текущие настройки TS-конфига с target ES6 для получения JS-файлов, используя `.js` в качестве расширения для модулей.
2.  **Создание индексного HTML**: для тестирования необходимо создать index.html, где через тег script подключается скомпилированный JS-файл.
3.  **Запуск в Браузере**: при попытке запуска в браузере напрямую, может возникнуть ошибка CORS. Для решения используется утилита `serve` для поднятия локального сервера.
4.  **Тип Модуля**: для использования ES модулей в браузере, важно указать `type="module"` в теге script.
5.  **Тестирование**: после настройки можно тестировать ваш JS как на бэкэнде, так и на фронте, используя браузер.

#### Общие Рекомендации:

-   **Современные Фреймворки**: большинство современных фреймворков, таких как React, Next.js, Vue и Angular уже предоставляют поддержку TypeScript "из коробки", что упрощает процесс настройки и сборки.
-   **Документация и Гайды**: в случае необходимости настройки сборки, ознакомьтесь с документацией по Rollup или Webpack, которая содержит всю необходимую информацию для работы с TypeScript.
-   **Плагины и Лоадеры**: для взаимодействия с TypeScript и инструментами сборки, используйте соответствующие плагины (`rollup-plugin-typescript`) и лоадеры (`ts-loader` для Webpack).
