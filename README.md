## 10.12. Порядок декораторов

**Цель эксперимента**: Изучить порядок выполнения декораторов в разных контекстах: класс, методы, свойства и параметры.

**1. Создание универсального декоратора (UniDecorator):**

-   Функция, принимающая имя и возвращающая функцию декоратора.
-   Пример использования на классе, методе, свойстве, статических элементах и параметрах.

**2. Назначение декоратора UniDecorator:**

-   Применение к классу, методам, свойствам (включая статические) и параметрам (в том числе конструктора).

**3. Порядок выполнения декораторов:**

-   **Не статические элементы**:
    -   Сначала выполняются декораторы свойств.
    -   Затем декораторы методов и их параметров (сначала метод, затем его параметры).
-   **Статические элементы**:
    -   Аналогично не статическим: сначала свойства, затем методы и параметры.
-   **Класс и его конструктор**:
    -   Декоратор класса выполняется после всех остальных декораторов.
    -   Порядок для конструктора и его параметров: сначала параметр, затем сам конструктор.

**4. Влияние порядка на работу декораторов:**

-   Порядок декорирования влияет только на элементы одного уровня (например, порядок свойств).
