## 12.5. Builder

#### Определение

Паттерн Builder (Строитель) - это порождающий паттерн, который позволяет создавать сложные объекты пошагово. Builder предлагает вынести конструкцию объекта за пределы его класса, разделив процесс создания на отдельные этапы, выполнение которых может происходить в разном порядке.

#### Применение

-   В ORM для построения запросов, например, Mongoose для MongoDB.
-   В генерации сложных объектов, например, изображений с различными параметрами.
-   В тестировании для создания сложных объектов, которые необходимы для запросов API.

#### Основные принципы

1.  **Chainable:** методы билдера можно вызывать последовательно в цепочке вызовов.
2.  **Простота для пользователя:** билдер скрывает сложность создания сложного объекта, предоставляя пользователю простые методы для добавления или настройки нужных параметров объекта.
3.  **Гибкость:** билдер позволяет создавать объекты с различными комбинациями свойств и характеристик без необходимости иметь множество конструкторов или фабрик.

#### Пример реализации

Рассмотрим пример создания генератора изображений. Нам необходимо управлять форматами (PNG, JPEG) и разрешением (ширина и высота).

1.  Определить класс `ImageBuilder` с приватным массивом форматов и разрешений.
2.  Методы для добавления формата (`addPng`, `addJpg`) и разрешения (`addResolution`), каждый из которых возвращает текущий экземпляр билдера для поддержки цепочек вызовов.
3.  Финальный метод `build`, который сочетает все предыдущие добавления и возвращает финальный объект/массив объектов с заданными характеристиками.

#### Преимущества использования паттерна Builder

-   Облегчает процесс создания сложных объектов.
-   Обеспечивает гибкость в управлении свойствами создаваемых объектов.
-   Упрощает код за счет цепочек вызовов и чёткого разделения этапов создания объекта.
