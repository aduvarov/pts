## 15.8. Упражнение - Шаблонный метод исполнителя

**Цель:** Разработать шаблонный метод исполнителя команд, следующий четырем стандартным этапам.

**Основные этапы:**

1.  **Абстракция и Реализация**:
    -   Создаем абстрактный класс `CommandExecutor`.
    -   Должен последовательно выполнить четыре шага.
    -   Реализовать абстрактные методы в классах-наследниках.
2.  **Структура Класса**:
    -   Конструктор принимает logger (`IStreamLogger`).
    -   Публичный асинхронный метод `execute` для выполнения команды.
    -   Защищенные абстрактные методы `prompt`, `build`, `spawn`, и `processStream`.
3.  **Подробное Описание Методов**:
    -   `prompt`: Ввод данных.
    -   `build`: Сборка команды с данными из `prompt`.
    -   `spawn`: Инициация и выполнения собранной команды.
    -   `processStream`: Обработка результата исполнения команды.
4.  **Реализация Этапов Исполнения**:
    -   Получение входных данных (`prompt`).
    -   Сборка команды (`build`).
    -   Выполнение команды (`spawn`).
    -   Обработка результата (`processStream`).
5.  **Типизация для Команды и Аргументов**:
    -   Создаем тип `iCommandExec` с полями `command` (строка) и `args` (массив строк).
