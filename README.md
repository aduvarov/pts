## 10.11. Метаданные

#### Основы:

-   Метаданные позволяют добавлять дополнительную информацию к вашему коду.
-   В JavaScript и TypeScript метаданные могут быть использованы для определения типов данных во время выполнения (runtime).
-   Библиотека `ReflectMetadata` используется для работы с метаданными, особенно в Angular и NestJS.
-   Метаданные могут быть полезны для dependency injection и типовой валидации.

#### Настройка проекта:

1.  Проверьте настройки `tsconfig.json` для включения `emitDecoratorMetadata`.
2.  Инициализируйте ваш проект с `npm init` и установите `reflect-metadata`.

#### Практика использования метаданных:

1.  **Добавление метаданных к методу:**
    -   Используйте `Reflect.defineMetadata` для добавления метаданных к методу.
    -   Это позволяет сохранять дополнительную информацию, например, какие параметры должны быть положительными числами.
2.  **Создание декоратора 'позитив':**
    -   Декоратор 'позитив' использует метаданные для маркировки параметров функции, которые должны быть положительными.
3.  **Валидация входных данных:**
    -   Создайте декоратор `validate`, который проверяет, соответствуют ли параметры функции сохраненным метаданным (например, являются ли они положительными).
    -   Переопределите функцию, используя descriptor, для добавления валидации параметров перед выполнением оригинальной функции.

#### Преимущества:

-   Обеспечивает типовую безопасность и валидацию данных в runtime.
-   Повышает читаемость и декларативность кода за счет использования декораторов для метаданных.
-   Позволяет разработчикам использовать типы TypeScript и метаданные для продвинутой логики в JavaScript.
